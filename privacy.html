Privacy policy

Last updated 30 September 2026.

What the app accesses

With the channel owner's permission, Pip Insights reads read-only YouTube Analytics and YouTube Data API information for the owner's own channels: video details and per-video metrics such as views, watch time, audience retention and traffic sources. It requests the yt-analytics.readonly and youtube.readonly scopes and cannot upload, edit or delete anything.

How the data is used and stored

The data is used only to measure how the owner's own videos perform. It is stored on the owner's computer. Access tokens are stored locally with owner-only file permissions.

Sharing

No data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Pip Insights' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
